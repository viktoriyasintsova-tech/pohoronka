# Каталог и материалы — 23.11.2026

Источник моделей: https://arkado-granit.ru/catalog/ritualnye-tovary/
Идеи для интерфейса: https://arkado-granit.ru/calculator/ (выбор стелы, надпись, портрет, комплектация). Чужой код конструктора и формы отправки не используются.

Импортированы 370 уникальных позиций: 332 варианта памятников объединены в 125 моделей; также добавлены 12 мемориальных комплексов, 11 надгробных плит, 8 ваз, 4 креста и 3 позиции покрытия. Ограждения и мебель с этого сайта исключены. Сохранены 22 изделия из пользовательского PDF и шесть серий памятников из актуального пользовательского прайса. Текстовый справочник дополнительных моделей из исходного Excel также сохранён. В общем каталоге 191 карточка, в конструкторе 131 модель и 370 вариантов размеров.

- Снимок фактических данных: `scripts/data/arkado-source-snapshot.json`.
- Сгруппированные модели: `src/extended-catalog.json`.
- Исходные изображения с адресами и контрольными суммами: `public/assets/arkado-reference/provenance.json`.
- Пять студийных иллюстраций переработаны встроенным image_gen; изображения и точные промпты: `public/assets/arkado-generated/`. Остальные изображения сохраняют исходную геометрию и оформляются единым компонентом каталога (фон, пропорции, поля).
- Фото пользовательской карты материалов: `public/assets/materials/samples.jpg`; координаты 13 образцов: `src/materials.js`. Девять образцов предназначены для памятников, шесть — для покрытия; Shanxi Black и Tan Brown входят в обе группы.

Все изображения размещены локально. Цены, гарантии, сроки, отзывы, контакты и заявки поставщика не переносятся. В импортированных моделях цены равны `null`; показывается «По запросу». Собственный актуальный прайс остаётся источником цен для прежних серий. При выборе другого материала цена уточняется отдельно.

Предпросмотр — собственный Canvas 2D. Контур соответствует изображению выбранного варианта; для изолированных стел учитывается отношение высоты к ширине. Идентификация изображения выполняется по ID исходной позиции, без подмены по похожему названию. Наложение образца камня приблизительное, не физически точный рендер или гарантия конкретного рисунка плиты. Текст, портрет и триплекс предназначены для согласования эскиза. Портрет остаётся в браузере и не записывается в сохранённый проект; итог можно скачать в PNG. Расчёт передаётся через существующее окно выбора связи.

## Проверка

```sh
node scripts/verify-catalog.mjs
GITHUB_ACTIONS=true npm run build
```

Проверка данных сопоставляет каждый исходный ID с вариантом в сгруппированном каталоге, проверяет локальные изображения, сохранность PDF-ассортимента и исключение чужих цен.

## Повторный импорт

Для Python нужны `requests` и `beautifulsoup4`. Скрипты запускаются из корня проекта:

```sh
python3 scripts/import-arkado-catalog.py
python3 scripts/build-extended-catalog.py
node scripts/verify-catalog.mjs
```

HTML при импорте кэшируется в `/tmp/istok-arkado-source`; публичный список стел конструктора использован как источник точных контуров (`/tmp/arkado-models.html`). Он получается запросом к `https://arkado-granit.ru/calculator/?action=getMonuments`. Проверять изменения поставщика перед обновлением каталога и не добавлять его цены в наш прайс автоматически.

Шрифт Jost размещён локально (`public/assets/fonts/`) с оригинальной лицензией SIL OFL, чтобы отрисовка интерфейса не зависела от Google Fonts. Источник: https://github.com/google/fonts/tree/main/ofl/jost .

## Обновление текстур — 23.11.2026

Все 13 материалов теперь используют отдельные локальные изображения из `public/assets/materials/textures/`, общие для образцов и 2D-предпросмотра. Это сгенерированные визуализации характера камня, а не фотографии конкретных плит. Исходная пользовательская карта сохранена в `samples.jpg`; её маленькие фрагменты с бликами больше не используются как текстуры. Точные промпты и порядок образцов сохранены в `textures/provenance.json`.

## Отрисовка объёма — 24.11.2026

Для шести базовых моделей из собственного прайса заданы отдельные геометрические маски лицевой, верхней и боковой поверхностей стелы и основания (`src/stone-surfaces.js`). Фон и падающая тень не перекрашиваются. Материал боковин отображается с отдельным затемнением и сжатием фактуры; основание использует другой участок рисунка. Исходное освещение сохраняет отражения полировки, фаски и глубину фрезеровки. Это собственный Canvas 2D-рендер с масками поверхностей, не полноценная 3D-модель.

Масштаб зерна гранита уменьшен. Случайно повёрнутые и смещённые участки смешиваются плавными весами без видимых стыков и симметричного повторения. Прожилки мрамора сохраняют крупный естественный рисунок. Геометрические маски привязаны к исходным изображениям 1254 × 1254: при замене фотографий их необходимо обновить. Импортированные модели используют общий подбор материала с сохранением исходного освещения; отдельные геометрические маски для них пока не размечены.

Проверки: `node scripts/verify-materials.mjs`, `node scripts/verify-catalog.mjs`, `npm run build`. `node scripts/review-materials.mjs /tmp/istok-materials.html` создаёт автономную HTML-страницу для браузерной проверки без сервера: 36 сочетаний шести форм и шести материалов, попиксельная проверка сохранности фона и теней. Параметр `?model=single-straight` ограничивает показ выбранной моделью. Прозрачность определяется до замены материала, чтобы светлые минеральные включения не превращались в отверстия.

## Мобильный конструктор — 24.11.2026

До 700 px компактный предпросмотр закреплён над настройками. Четыре кнопки переключают модель, камень, оформление и комплектацию; открыт один шаг. «Крупнее» открывает существующий увеличенный просмотр. Прокрутка к объекту при смене модели, размера или материала происходит только если он вне экрана. Текст и ползунки не вызывают автопрокрутку. На низких экранах до 540 px высотой закрепление отключается, чтобы оставить место для управления. Учтено предпочтение уменьшенного движения; размер шрифта полей — 16 px, основные области нажатия — от 44 px.

`node scripts/review-mobile.mjs /tmp/istok-mobile.html` собирает реальные React-компоненты в автономную страницу без сервера. Открывать с `?page=builder`; для Canvas браузеру нужен доступ к локальным изображениям. Проверены размеры 320 × 568, 390 × 844 и 1440 × 1000: переключение шагов, закрепление объекта, выбор материала и ввод без скачков, увеличение и восстановление прокрутки, отсутствие горизонтального переполнения, сохранность десктопной сетки.

## Материалы в каталоге и плитка — 26.11.2026

Выбор материала общий для карточек каталога, главной, связанных товаров и страницы товара (`MaterialPicker`). Образцы памятников совпадают с конструктором; для покрытия доступны граниты карты образцов и «Жемчужный цветок», для бетонной плитки — серый, графит, коричневый, красный и песочный. Металлические изделия не предлагают камень. Выбор передаётся через URL в товар, затем в конструктор и текст обращения. Для заказного материала цена уточняется. На мобильных устройствах применены подписанные нативные списки, шрифт полей 16 px, области нажатия от 48 px; до 430 px карточки идут одной колонкой.

В `paving-catalog.json` добавлены 7 гранитных плиток и 2 бетонные формы. Размеры гранита взяты из https://arkado-granit.ru/catalog/granitnaya-plitka/ и индивидуальных страниц: 600 × 300 × 20 мм, кроме «Спелого персика» — 600 × 300 × 18 мм. Снимок размеров: `scripts/data/paving-source.json`; фотографии сохранены в `public/assets/paving/`, их источники — в `provenance.json`. Цены поставщика не импортируются.

«Кирпичик»: 200 × 100 мм, толщина 40/60/80 мм — https://braer.ru/catalog/trotuarnaya-plitka/trotuarnaya-plitka-pryamougolnik-pesochnyj-h-60-mm/ . «Старый город»: комплект 172/115/86 × 115 × 60 мм — https://artikospb.ru/f/prajs-list.pdf . Формы и оттенки являются предварительным ассортиментом для согласования; наличие и поставщик подтверждаются перед заказом. Изображения бетонной плитки — собственные SVG-визуализации геометрии, а не фотографии партии. Гарантии и эксплуатационные характеристики производителей не перенесены.

Ориентиры для сенсорного интерфейса: https://developer.apple.com/design/tips/ и https://support.google.com/accessibility/android/answer/7101858?hl=en . Это адаптивный веб-интерфейс, не сертификация нативного приложения. Проверка каталога в браузере без сервера: `node scripts/review-catalog.mjs /tmp/istok-catalog.html`, затем открытие с `?page=paving`. Проверяется выбор материала, передача в URL, цена по запросу, область нажатия и отсутствие горизонтального переполнения.

## Компактная витрина и настройка товара — 26.11.2026

На главной шесть базовых форм выведены компактной сеткой (две колонки на телефоне): изображение, короткое название и «Подробнее». Настройка материалов остаётся на странице товара. В общем каталоге материалы показываются подписанными кружками в прокручиваемой строке, на странице товара — сеткой нативных radio-кнопок. Есть отдельный выбор исходного материала, клавиатурная навигация и видимое выделение активного образца.

Общий шаблон товара теперь содержит заголовок перед изображением, затем материал и размер. На телефоне компактное изображение закреплено над параметрами, выбранные материал и размер подписаны под ним. Характеристики перенесены в раскрываемый блок. Предпросмотр не требует прокручивать страницу обратно к началу после каждого выбора. На низких экранах закрепление отключается.

В списках каталога одна карточка «Плитка для благоустройства» объединяет семь гранитов, пять оттенков бетона и обе бетонные формы. Исходные товары и старые URL сохранены. `paving-products.js` выбирает исходную модель и точный размер по материалу и форме. Сначала отображается крупный квадрат образца, вторым изображением — вид в плитке; доступны свайп и кнопки. Галерея общая для каталога и страницы товара. Для «Спелого персика» сохраняется толщина 18 мм. Гарантии и наличие не добавлены, стоимость по запросу.

Автономные проверки `review-catalog.mjs`/`scripts/data/catalog-ux-checks.js` покрывают главную, единый каталог плитки и товар: порядок заголовка, визуальные образцы, передачу материала в конструктор, корректную толщину, два изображения плитки, отсутствие скачков и горизонтального переполнения. Проверены мобильные 320/390 px и десктоп 1440 px.

## Полная проверка материалов и новые модели — 26.11.2026

Убрана пороговая перекраска импортированных фотографий: зеркальный блик и тень на камне больше не исключаются только из-за яркости пикселя. Прозрачные силуэты используют исходный альфа-контур целиком. Серые полосы чертежей нормализуются как фаска; добавлена иллюстративная толщина торца по размеру плиты, если он известен. Это глубина в Canvas 2D, а не загруженная измеренная 3D-модель.

В `stone-segmentation.js` студийный фон отделяется как связанная область. Для тёмных изделий фон определяется с учётом плавной светотени, для исходного светлого мрамора это расширение отключено, чтобы не принять поверхность камня за фон. Оригинальная падающая тень сохраняется. Защита травы использует крупные связанные области и заполнение тёмных промежутков: отражение газона на лицевой плоскости не становится «дырой» в новом материале. Маски и текстурные поля кэшируются с ограничением памяти.

`node scripts/review-all-stones.mjs /tmp/stones.html` создаёт автономную страницу для полного браузерного прогона каждого варианта с девятью материалами и визуального обзора первых вариантов моделей. Параметром после пути можно передать список ID через запятую для крупного сравнения. Проверки контролируют загрузку, применение каждого материала и отсутствие расширения непрозрачности фотографий; иллюстративная толщина допускается только для прозрачных контуров. Они не являются доказательством физической точности конкретной плиты. Все 157 моделей / 396 вариантов проходят 3564 сочетания; дефекты со скриншотов дополнительно просмотрены крупно. Регрессии включают внутренние светлые пиксели, блики, тёмные промежутки в траве, отражение травы на стеле и непрерывность текстур.

Из пяти пользовательских фотографий буклета выявлено 75 подписанных позиций: 49 сопоставлены существующим моделям, 26 добавлены в `src/user-catalog.json`. Таблица решений — `scripts/data/user-catalog-plan.json`. Частично обрезанные изображения соседнего разворота не добавлены. Размеры и цены в исходниках не указаны: показаны индивидуальные размеры и цена по запросу. Первоначальная модель конструктора из собственного прайса сохранена.

Каждый из 26 новых объектов восстановлен отдельным вызовом встроенного `image_gen` по своему референсу: нейтральная студийная подача, форма, основание и декор из буклета. Итоговые JPEG: `public/assets/user-catalog/`; точные промпты, имена исходников и их SHA-256: `public/assets/user-catalog/provenance.json`. Генеративная реконструкция не является обмером или фотографией выполненного заказа; мелкие детали резьбы требуют согласования по исходному каталогу/эскизу. Исходные PNG сохранены инструментом в generated_images, JPEG оптимизированы для сайта; суммарно около 7.4 МБ на 26 товаров.

На главной удалена витрина отдельных памятников, конструктор и остальные разделы сохранены. «Услуги и изделия» оформлены в шесть бенто-карточек с изображениями, затемнением и ссылкой в раздел. Устранено специальное исключение для «Жемчужного цветка»: второй слайд теперь рисует плитку с выбранной фактурой, а не повторяет плоский образец.

Для обсуждения с заказчиком: «Визуализация показывает выбранную форму, сочетание материалов и оформление. Точный природный рисунок плиты и детали резьбы согласуем по образцу и рабочему эскизу». Для точной передачи изделия потребуются обмерные 3D-модели, разделённые поверхности и съёмка/PBR-карты реальных каменных слэбов; нынешний сайт не заявляет такого уровня измерительной точности.
